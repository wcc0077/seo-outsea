# RFID电子标签产品目录

> 注：rfid-tag.html 实际内容为超高频读写器产品，电子标签页面内容需从其他来源补充。

## 已识别的标签类别（从导航结构）

| 类别 | 说明 |
|------|------|
| 工业载码体 | 工业级RFID载码体，耐高温、抗金属等 |
| 耐高温标签 | 适用于高温环境的RFID标签 |
| 抗金属标签 | 适用于金属表面的RFID标签 |
| 易碎防转移标签 | 防伪、防拆场景使用 |
| 智能卡与不干胶标签 | 标准RFID卡片和标签 |
| 其他特种标签 | 定制化特种应用标签 |
| 有源电子标签 | 有源RFID标签（自带电池） |

## 导入Strapi建议

每个电子标签产品应包含以下字段：
- `name`: 产品名称
- `tagType`: 标签类型（载码体/耐高温/抗金属/易碎/智能卡/特种/有源）
- `frequency`: 工作频率（LF/HF/UHF/有源）
- `description`: 产品描述
- `features`: 特性（耐温、抗金属、尺寸等）
- `imageUrl`: 产品图片URL
- `applicationScenarios`: 适用场景
- `specs`: 技术参数（尺寸、材质、工作温度、读写距离等）
